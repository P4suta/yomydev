# Yomydev

Let AI agents check whether you're at your Mac before they wait on you.

## Installation

```sh
cargo install --locked --git https://github.com/P4suta/yomydev yomydev
claude mcp add --scope user yomydev -- ~/.cargo/bin/yomydev mcp
yomydev grant
```

## Usage

```sh
yomydev check
```
